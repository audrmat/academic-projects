# Academic Projects Portfolio

Welcome to my academic portfolio. This repository gathers the main projects and practical assignments completed during my Master in Business Analytics at HEC Lausanne.

The purpose of this space is to showcase my technical skills, my working methodology, and my ability to apply theoretical concepts to concrete cases.

## Projects List
### Français:

| Nom du projet | Description | Technologies | Lien du Dossier |
|---|---|---|---|
| **Rebooster le tourisme à Lausanne** | Analyse exploratoire de données (EDA) des arrivées et nuitées hôtelières suisses (2013-2025) afin d'identifier des marchés internationaux émergents (Brésil, Singapour, Arabie Saoudite) et élaboration d'un calendrier événementiel stratégique pour réduire la saisonnalité touristique. | Python, Pandas, Seaborn | [📁 View project](./data-analysis/market-analysis-lausanne-tourism) |

| **Analyse des facteurs du Cancer du Sein** | Analyse exploratoire (EDA) d'un large jeu de données pour étudier les facteurs de risque du cancer du sein, notamment les associations entre la densité mammaire, les antécédents et les caractéristiques des patientes. | Python, Pandas, NumPy, Matplotlib, Seaborn | [📁 View project](./data-analysis/risk-factors-breast-cancer) |
